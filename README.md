# Zelfrijdende-auto-
We maken een zelfrijdende auto. 

De is een afbeelding van onze zelfrijdende auto 
<img width="569" height="588" alt="image" src="https://github.com/user-attachments/assets/f2a7193b-7e90-4c1a-a9d7-8fc00b526260" />

De Arduino stuurt de motoren aan via een H-brug. Hierdoor kan de auto verschillende richtingen uit rijden.

De auto kan:

2 seconden vooruit rijden.

2 seconden naar links draaien.

2 seconden naar rechts draaien.

2 seconden achteruit rijden.

De pinnen van de H-brug hebben we aangesloten op:
   int ENA = 5;
   int IN1 = 8;
   int IN2 = 9;
   int IN3 = 10;
   int IN4 = 11;
   int ENB = 6;
